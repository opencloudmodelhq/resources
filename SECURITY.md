# Security policy

## Reporting a vulnerability

Report privately through **GitHub private vulnerability reporting**: open the repository's
**Security** tab and choose **Report a vulnerability**. Do not open a public issue.

Include what is affected, how to reproduce it, and the impact you expect.

## What to expect

- Acknowledgement within 14 days.
- A fix or a mitigation plan agreed with you, then coordinated disclosure, normally within 90 days.
- Credit in the advisory unless you ask otherwise. There is no bug bounty.

## Scope

- Code, workflows and release artefacts of opencloudmodelhq repositories.
- **Data integrity**: a published value that was altered, or that does not match its cited source,
  is in scope.

## Supported versions

Only the latest release of each repository receives fixes.
