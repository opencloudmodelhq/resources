# Code of conduct

OpenCloudModel projects adopt the
[Contributor Covenant, version 3.0](https://www.contributor-covenant.org/version/3/0/code_of_conduct/).

## Reporting

Report conduct concerns privately through GitHub: open the repository's **Security** tab, choose
**Report a vulnerability**, and say that the report is about conduct. That form reaches only the
maintainer. The maintainer reads every report, keeps the reporter's identity private, and replies
within 14 days.

If the concern is about the maintainer, use GitHub's own
[report abuse](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)
form instead. The project has one maintainer and no second contact yet.

## Enforcement

Enforcement follows the Contributor Covenant 3.0 enforcement ladder: correction, warning,
temporary ban, permanent ban.
